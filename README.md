# TP-F1-Argentina
Repositorio del TP2 de Ciencia de Datos e IA (ESIM ISFDyT) sobre la historia de Argentina en la Fórmula 1. Incluye la recolección y análisis de datos (1950–2025), limpieza, exploración, visualización en Power BI y respuesta a preguntas de investigación sobre el desempeño histórico de los pilotos argentinos.
